# اپلیکیشن «ما و شهید گمنام»

نسخه اولیه اندرویدی با Kotlin + Jetpack Compose.

امکانات فعلی:
- صفحه اصلی اختصاصی
- عنوان و معرفی کتاب
- فهرست کامل فصل‌ها بر اساس متن ارسالی
- حالت روشن/شب
- ساختار آماده برای افزودن متن کامل فصل‌ها، جست‌وجو، نشانک و ادامه مطالعه

توجه: متن ارسالی در انتهای فصل دوم ناتمام بود و متن کامل فصل‌های سوم تا پنجم و مؤخره در پیام موجود نبود؛ بنابراین این نسخه عمداً متنِ ناقص را به‌عنوان متن کامل کتاب جا نمی‌زند.
